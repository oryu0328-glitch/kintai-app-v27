勤怠管理表 v27.0.0

【追加】
・画面下のタスクバー：ホーム／カレンダー／スタッフ／給与計算／その他
・「その他」→タスク管理（追加・完了・削除）
・「その他」→デザイン設定（ピンク／ブルー／グリーン／ベージュ／ダーク）
・スマホホーム画面用icon-192.png、icon-512.png、apple-touch-icon.png、Web用favicon.ico
・PWA manifest.webmanifest

【従来機能】
v26の打刻、勤怠履歴、カレンダー、給料日、給与シミュレーション、個人別月額給与を維持しています。
スタッフ管理はスタッフタブ、勤務履歴はその他タブ、バックアップは給与計算タブの月間集計にあります。

【重要】
更新前にv26からJSONバックアップを保存してください。保存場所/URLが変わるとデータが引き継がれない場合があります。
実際のホーム画面アイコン設定にはHTTPS配信とブラウザの「ホーム画面に追加」が必要な場合があります。
